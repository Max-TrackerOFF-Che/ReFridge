# ❄️ ReFridge

Застосунок, який допомагає знати, що лежить у холодильнику, вчасно використовувати продукти та менше викидати їжі.

## Можливості

- **Облік продуктів**: назва, кількість, категорія, термін придатності.
- **Контроль свіжості**: продукти сортуються за терміном; кольорові позначки показують, що свіже, що скоро зіпсується (≤ 2 днів), а що вже прострочене.
- **Підбір рецептів**: рецепти ранжуються за часткою інгредієнтів, які вже є, а вище стоять ті, що використовують продукти, яким скоро спливає термін. Також видно, що треба докупити.
- **Офлайн**: дані зберігаються в `localStorage` браузера, сервер не потрібен.

## Запуск

Збирати нічого не треба, це чистий HTML/CSS/JS (ES-модулі). Модулі не працюють через `file://`, тому потрібен будь-який статичний сервер:

```bash
cd refridge
npm start            # або: python3 -m http.server 5173
```

Відкрийте http://localhost:5173.

## Тести

```bash
cd refridge
npm test             # node --test, потрібен Node 20+
```

## Структура

```
refridge/
├── index.html        # розмітка сторінки
├── src/
│   ├── app.js        # UI: форма, список, рендер рецептів
│   ├── logic.js      # чиста логіка: терміни, сортування, підбір рецептів
│   ├── recipes.js    # базова книга рецептів
│   ├── store.js      # збереження в localStorage
│   └── styles.css    # стилі (світла/темна тема)
└── test/
    └── logic.test.js # юніт-тести логіки
```
