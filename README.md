# ❄️ ReFridge

Інтерактивний холодильник у браузері: допомагає знати, що в ньому лежить, вчасно використовувати продукти та менше викидати їжі.

## Можливості

- **Настрій холодильника**: ретро-холодильник на кухні має обличчя й підсвітку, які показують стан продуктів:
  - 🔴 плаче — прострочено більше 10% продуктів;
  - 🟢 усміхається й іскриться — прострочених немає, а найближчий термін спливає щонайменше через 5 днів;
  - ⚪ спокійний — усе інше (зокрема, коли частина продуктів псується за 2 дні або менше).
  Бульбашка поруч пояснює, що саме не так, а очі стежать за курсором. На стіні висить справжній годинник.
- **Живий холодильник**: дверцята морозилки й основної камери відчиняються з 3D-анімацією, всередині вмикається світло. Продукти стоять на полицях (молочне, м'ясо, крупи, інше), а овочі й фрукти лежать у шухлядах.
- **Розумне додавання**: за назвою продукту застосунок сам підбирає емодзі, полицю й типовий термін придатності.
- **Вільне розміщення**: продукт можна перетягнути мишею або пальцем у будь-яке місце будь-якої полиці. Він прилипає там, де його відпустили, а якщо місце зайняте, то на найближчому вільному. Нові продукти стають у перший вільний ряд знизу. Позиції зберігаються.
- **Контроль свіжості**: кольорова крапка на кожному продукті; те, що скоро зіпсується (≤ 2 днів), пульсує, а прострочене «тухне» й хитається. Якщо всередині щось псується, на зачинених дверцятах блимає індикатор.
- **Магніти на дверцятах**: скільки всього продуктів, скільки псуються, скільки використано вчасно і скільки викинуто.
- **Стікер «Що приготувати?»**: топ-3 рецепти на дверцятах, а натискання відкриває повний список. Рецепти ранжуються за часткою інгредієнтів, які вже є, а вище стоять ті, що використовують продукти, яким скоро спливає термін. Також видно, що треба докупити.
- **Офлайн**: дані зберігаються в `localStorage` браузера, сервер не потрібен.

## Запуск

Збирати нічого не треба, це чистий HTML/CSS/JS (ES-модулі). Модулі не працюють через `file://`, тому потрібен будь-який статичний сервер:

```bash
cd refridge
npm start            # або: python3 -m http.server 5173
```

Відкрийте http://localhost:5173.

## Тести

```bash
cd refridge
npm test             # node --test, потрібен Node 20+
```

## Структура

```
refridge/
├── index.html        # розмітка сторінки
├── src/
│   ├── app.js        # UI: дверцята, полиці, перетягування, діалоги
│   ├── logic.js      # чиста логіка: терміни, сортування, підбір рецептів
│   ├── placement.js  # вільне розміщення значків: пошук найближчого вільного місця
│   ├── products.js   # розпізнавання продукту: емодзі та полиця
│   ├── recipes.js    # базова книга рецептів
│   ├── store.js      # збереження продуктів і статистики в localStorage
│   └── styles.css    # холодильник, анімації, світла/темна тема
└── test/
    └── logic.test.js # юніт-тести логіки
```
